## 📚 목차 및 학습 내용

### Part 1. 스프링 부트 개요

| 장 | 제목 | 학습 내용 |
|---|---|---|
| 1장 | 스프링 부트 시작하기 | 스프링 부트 개요, 개발 환경 설정, 웹 서비스 동작 원리 |
| 2장 | MVC 패턴 이해와 실습 | 뷰 템플릿, MVC 패턴, 레이아웃 적용 |

### Part 2. 게시판 CRUD 만들기

| 장 | 제목 | 학습 내용 |
|---|---|---|
| 3장 | 게시판 만들고 새 글 작성하기: Create | 폼 데이터, DTO, JPA 저장 |
| 4장 | 롬복과 리팩터링 | Lombok을 활용한 코드 간소화 |
| 5장 | 게시글 읽기: Read | 단일/목록 데이터 조회 |
| 6장 | 게시판 내 페이지 이동하기 | 링크, 리다이렉트 |
| 7장 | 게시글 수정하기: Update | 수정 페이지, DB 갱신 |
| 8장 | 게시글 삭제하기: Delete | 데이터 삭제 흐름 |
| 9장 | CRUD와 SQL 쿼리 종합 | JPA 로깅, SQL 쿼리 작성 |

### Part 3. REST API와 테스트 코드 작성하기

| 장 | 제목 | 학습 내용 |
|---|---|---|
| 10장 | REST API와 JSON | REST API 등장 배경 및 개념 |
| 11장 | HTTP와 REST 컨트롤러 | REST API 구현 |
| 12장 | 서비스 계층과 트랜잭션 | 서비스 레이어, 트랜잭션 처리 |
| 13장 | 테스트 코드 작성하기 | JUnit 기반 테스트 작성 |

### Part 4. 댓글 CRUD 만들기

| 장 | 제목 | 학습 내용 |
|---|---|---|
| 14장 | 댓글 엔티티와 리파지터리 만들기 | 연관 관계 매핑, 커스텀 쿼리 |
| 15장 | 댓글 컨트롤러와 서비스 만들기 | 댓글 REST API 전체 구현 |
| 16장 | 웹 페이지에서 댓글 목록 보기 | 뷰 페이지 연동 |
| 17장 | 웹 페이지에서 댓글 등록하기 | JavaScript fetch API |
| 18장 | 웹 페이지에서 댓글 수정하기 | 비동기 수정 처리 |
| 19장 | 웹 페이지에서 댓글 삭제하기 | 비동기 삭제 처리 |
